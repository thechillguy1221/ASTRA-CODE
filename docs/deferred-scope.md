# Deferred scope

The following are deliberately not part of the first Windows agent milestone:

- public marketing website;
- `apps/web` and `apps/admin`;
- commercial wallet, Razorpay, subscription billing, or credit charging;
- marketplace, MCP, Skills, and Plugins product surfaces;
- student modes and collaboration features;
- cloud-uploaded repository workspaces;
- broad multi-language verification certification;
- packaged distribution, signing, auto-update, and production deployment automation.

The database already has an immutable credit-ledger shape so billing can be added without rewriting task and usage data. The model catalog and usage receipt boundaries are active now because changing provider routing and accounting later would otherwise require a risky retrofit.

The next expansion should be selected only after the deterministic golden path, desktop adapter, and opt-in live smoke have been run in a real Windows environment with the intended API and database configuration.
