# Astra Cline workspace component provenance

This matrix distinguishes Cline-owned agent interaction components from IDE
primitives that Astra owns. It is intentionally conservative: the pinned Cline
SDK does not own the VS Code editor, file explorer, terminal, search, Problems,
or Git surfaces used by Astra's native workspace.

Pinned source: `vendor/upstream/cline` at
`9a2512bb9835869d74774da99708a7f9d80b0fe8`.
